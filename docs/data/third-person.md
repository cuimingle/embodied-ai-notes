# 第三视角：从旁观者的位置理解行动

第三视角描述的是**相机与行动主体的关系**：相机从身体外部观察人或机器人。它可以是固定机位，也可以是跟拍机位；可以记录真实世界，也可以由仿真渲染。因此，它与遥操、HumanCentric、仿真会重叠，不能把这几类当成互斥的数据来源。

它的价值在于看清“谁在什么位置，对什么物体做了什么”，尤其适合全身运动、人与物体关系、多人协作和长任务的阶段变化。但看见一次抓取，不等于知道机器人应该输出多少关节力矩。

## 怎样采集

一条典型流程是：**布置外部相机 → 标定与同步 → 记录完整活动 → 标注动作和对象 → 按场景或主体划分数据**。多机位可以互补遮挡，配合深度相机或姿态估计得到人体几何信息。若同时记录头戴相机，还能建立同一事件的第一、第三视角对应。

采集机器人操作时，可以把外部视频与遥操指令、编码器和夹爪状态同步保存；拍摄普通人类活动时，通常只有视频、动作标签或人体姿态。**两者都叫第三视角，能训练的模块却不同。**

人体关键点可能来自估计器，也可能结合专门的采集设备生成；使用时要确认来源、置信度和缺失值，不能统一当作精确真值。

## 在具身系统中的位置

**感知与理解是直接用途。** 第三视角适合学习动作边界、物体交互和任务阶段，作为视频编码器、技能识别器或进度估计器的训练材料。用于奖励模型时，还需要定义成功条件并验证判断可靠性；“动作类别正确”并不保证任务完成。

**从视频迁移到控制需要额外环节。** 人类视频可以提供动作顺序和运动先验，但机器人还需要解决视角转换、身体差异、接触约束和动作标定。若数据已经包含同步的机器人指令，才可以直接构建相应动作空间中的行为克隆样本。这里的用途判断是根据可用字段作出的分析，并非下面每个数据集都提供了机器人策略训练接口。

这些项目展示的是三种监督深度：**动作语义、手部操作过程、全身运动结构**。选数据时应先确定目标模块，再比较视角与标注，而不是仅按视频时长排序。

另一个常见资源是 [Something-Something V2](https://www.qualcomm.com/developer/software/something-something-v-2-dataset)：众包拍摄预定义的物体交互动作，并提供动作标签和部分对象文字标注。官方介绍并未把所有视频限定为严格的第三人称机位，因此这里把它列为相关动作视频资源；使用前仍需检查实际视角。它也不提供可直接执行的机器人控制标签。

## 使用前检查四件事

1. **切分是否泄漏。** 同一次动作的不同相机视频应归入同一数据分区；否则模型可能在测试时见到训练事件的另一个角度。
2. **视角是否可迁移。** 固定的俯视机位、整洁桌面和无遮挡人体，可能与部署时的腕部相机或拥挤场景差异很大。
3. **时序是否完整。** 剪辑后的成功片段可能缺少尝试、失败和恢复，不能替代闭环交互数据。
4. **动作与姿态是否混淆。** “打开抽屉”是语义标签，手腕轨迹是运动观测，末端位姿指令才是某类控制标签；三者需要分别建模。
