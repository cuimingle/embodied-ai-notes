# 强化学习扩展：从 Actor-Critic 继续

赵世钰教材的十章主线到[第 10 章 Actor-Critic](../rl/10-actor-critic.md)结束。下面四篇介绍教材之外的策略优化方法，沿用教材的 $v_\pi,q_\pi,\pi(a\mid s,\theta),\delta_\pi$，新增记号在各篇中定义。

## 四种策略优化方法

| 方法 | 重点 | 数值实验 |
| --- | --- | --- |
| [TRPO](trpo.md) | 用 KL 约束控制策略更新 | Bernoulli 策略的新旧分布差异 |
| [PPO](ppo.md) | 裁剪代理目标，配合优势估计 | 正负优势下的分段目标 |
| [GRPO](grpo.md) | 回答组内的相对奖励信号 | 奖励与标准化优势 |
| [GSPO](gspo.md) | 长度归一化的序列比率 | token 比率与几何平均 |

## 数值实验的范围

每个实验只计算表中列出的目标函数或统计量。GRPO 与 GSPO 的示例使用回答奖励和 token 序列，策略在机器人上的表现还要通过控制任务验证。[从 RL 到具身任务](../rl/to-embodied.md)介绍怎样为机器人定义状态、动作与奖励。
