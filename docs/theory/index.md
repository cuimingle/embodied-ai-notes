# 理论基础

盘子左边是一只蓝杯，右边是一只白杯。你对机器人说：“把盘子左边的杯子递给我。”它可能听对了每个字，却伸手去拿白杯。它也可能找对了蓝杯，手指却合拢得太早。这些错误发生在不同环节，适合从不同方向入手。

## 从一个问题找到对应方向

| 你想弄清什么 | 从这里开始 |
| --- | --- |
| 一次抓取可能要到最后才知道成败。怎样用这些反馈改进一连串动作？ | [强化学习](../rl/index.md)从奖励、回报与策略讲起。教材主线共十章，之后可进入[进阶专题](../extensions/index.md)。 |
| 已经找到杯子，机器人下一步该怎么伸手、什么时候合拢夹爪？ | [策略模型](../policies/index.md)用 ACT、SmolVLA 和 π₀ 对照不同策略的输入、动作表示和执行方式。 |
| 指令改成“把它递给我”，怎样结合前文解释“它”指什么？ | [语言模型](language.md)介绍模型怎样利用文本上下文，以及指令中缺少信息时为什么需要追问。 |
| 在嘈杂房间里，机器人怎样听清“盘子左边”？ | [语音模型](speech.md)从声音信号讲到转写，说明一次漏词怎样改变整条指令。 |
| 画面中有两只杯子，怎样把“盘子左边”对应到正确的那一只？ | [多模态模型](multimodal.md)讨论语言与图像怎样共同确定目标，以及怎样检验模型是否真的用到了两种信息。 |

## 沿着一次失败往回查

如果机器人拿错了杯子，可以先读转写，看“左边”有没有被听成“右边”。再让它在照片上指出目标：第一次应指向蓝杯。交换两个杯子的位置，重新拍照并重复同一句指令，这次应指向白杯。如果两次都指对了，再回看伸手和闭合时的相机图像、夹爪位置和动作记录。这样就能分别检查听觉、指代和动作执行。

同一台机器人可以同时用到这五个方向。策略可以从人的示范中学，也可以用强化学习继续改进。想看这些环节怎样接在一起，可以读[具身智能的主要技术栈](../quick-overview/stack.md)；想比较抓取、操作、运动和导航各自如何判断成功，可以读[具身智能主要解决哪些任务](../quick-overview/tasks.md)。
