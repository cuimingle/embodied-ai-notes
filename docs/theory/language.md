# 语言模型

“把托盘上的蓝杯放进白盒”和“把蓝杯放进托盘上的白盒”用到了同样的词，机器人却该去不同的地方找目标。第一句说的是杯子在哪里，第二句说的是盒子在哪里。

## 从词语读出动作、对象和参照

在这个例子里，语言模块的输入是指令文本，输出可以是一组供下游查询的条件。第一句指定要移动**蓝杯**，找杯子的线索是**在托盘上**，完成条件是**蓝杯在白盒里**。如果接下来只说“把它拿出来”，“它”指谁就要结合前一句来判断。

GPT-3 这类**自回归语言模型**把指令、对话历史和已经生成的文字拆成词元（token），根据上文预测下一个词元，再把它接在上文后继续生成。词元可以是一个词，也可以是词的一部分。给模型几组“指令与目标条件”的例子，就可以让它按相同格式回答新的指令。[GPT-3 原论文](https://proceedings.neurips.cc/paper/2020/hash/1457c0d6bfcb4967418bfb8ac142f64a-Abstract.html)

有些歧义得靠新信息解决。如果相机在托盘上找到了两只蓝杯，原话没有给出选择依据，系统可以把两个候选的区别写进追问里：“你要有杯柄的那只，还是没有杯柄的那只？”人的回答就成了下一轮可用的上下文。

## 把语言目标交给机器人

假设蓝杯已经找到，白盒还在另一个房间。此时“把杯子放进盒里”准确表达了目标，但机器人当下能做的第一步可能是抓杯或移动。SayCan 用语言模型给已有技能打分，衡量哪一个有助于推进指令，再用每个技能的价值函数估计它在眼前状态下能否成功。两项分数共同决定下一步。[SayCan 原论文](https://proceedings.mlr.press/v205/ichter23a.html)

读机器人演示时，可以分别记下系统选中了哪个物体、调用了哪个技能、执行后物体在哪里。这样即使最终放错盒子，也能回头查清是指令读错、场景认错，还是动作没有完成。观察如何与指令结合，见[多模态模型](multimodal.md)。
