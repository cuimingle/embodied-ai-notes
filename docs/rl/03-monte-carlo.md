# 03 · Monte Carlo learning

> 状态：整理初稿。MC 实验尚未实现。

## 用完整回报估计价值

已知转移模型时可以做期望备份；只有交互轨迹时，可以把真实采样到的回报 $G_t$ 当作 $V^\pi(S_t)$ 的样本。在终止任务中，通常要等一条轨迹结束后才能得到完整回报。

对固定状态 $s$ 收集 $n$ 个回报样本，估计 $V_n(s)=\frac1n\sum_{i=1}^nG_i$。增量写法为：

$$
V_n(s)=V_{n-1}(s)+\frac1n\left[G_n-V_{n-1}(s)\right].
$$

增量公式避免保存全部回报，且在使用 $1/n$ 步长时仍等价于样本均值。常数步长会得到不同的、偏向近期样本的估计。

## First-visit 与 every-visit

First-visit MC 每条轨迹只使用对状态的第一次访问；every-visit 使用所有访问。后者同一轨迹内的回报相关，不能把访问次数直接解释为独立样本数。

例如轨迹 $A\to B\to A\to T$，first-visit 对 $A$ 只使用第一个回报，every-visit 还使用第二次到达 $A$ 时的回报。转写手稿时应标清“第一次”按正向时间判断，避免倒序计算回报时写成 last-visit。

## 从评估到控制

评估固定策略只回答该策略表现如何。MC control 还要估计 $Q(s,a)$，根据估计改进策略，并保证足够探索。仅靠完全贪心动作可能永远不尝试早期被低估的动作。

On-policy 数据来自正在评估或改进的策略。若数据来自另一行为策略 $b$，则涉及 off-policy 估计；重要性采样需要目标策略的支持被行为策略覆盖，其权重也可能带来较大方差。

## 与 TD 的关系

MC 的目标使用采样后的完整回报，不使用下一状态的价值估计进行自举。轨迹越长，回报受未来随机性的影响通常越大。TD 提前用估计值补上未来，因此改变了偏差与方差的来源。
