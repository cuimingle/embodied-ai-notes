# 11 · Group Relative Policy Optimization

> 状态：概念初稿。采用语言模型的结果监督设定，完整推导与实现待补。

## 从哪里构造优势

在 [DeepSeekMath](https://arxiv.org/html/2402.03300v3) 的 GRPO 中，同一问题 $x$ 由旧策略生成一组回答 $\{y_i\}_{i=1}^G$。结果监督可将回答得分组内标准化：

$$
\hat A_i=\frac{R_i-\operatorname{mean}_jR_j}
{\operatorname{std}_jR_j}.
$$

同一回答的各 token 共享这个信号，因而无需另训价值模型。实际实现需处理标准差为零的组，并记录标准差口径与数值稳定项。

## 与 PPO 比较什么

原始 GRPO 使用 token 级新旧策略比率和裁剪代理目标，同时包含相对参考策略的 KL 正则。**旧策略**用于说明数据由谁生成，**参考策略**用于约束偏离，两者作用不同。

这里仅展示优势构造，未把它当成完整 GRPO 目标。转写手稿时还需要补齐 token 聚合、回答长度权重、KL 项与采样期望；过程监督版本也需单列。

## 手算与自检

取组奖励 $[0,0,1,1]$，使用总体标准差，均值 $0.5$、标准差 $0.5$，得到优势 $[-1,-1,1,1]$。若奖励全相等，标准化前没有组内区分信号。

组归一化后的信号不应直接称为精确优势函数。进入机器人实验时，需重新定义组内任务条件、重置分布、轨迹奖励和采样成本。
