# 具身智能的主要技术栈，一条动作是怎样产生的？

具身智能快速概览 · 第三篇

假设桌面摄像头拍到了蓝杯子。图像系统给它画了一个非常准的框，机械臂仍然不知道该把哪一个关节转多少度。这个框的位置用像素表示，杯子离相机多远、夹爪从哪边进得去、电机能否跟上，都是接下来要回答的问题。沿着这条动作往下走，就能把技术栈串起来。

## 从一张图到一次伸手

| 环节 | 在抓杯这件事里做什么 | 交给下一环的东西 |
| --- | --- | --- |
| 本体、传感器与执行器 | 机械结构决定够得到哪里。相机拍图，编码器读关节，电机驱动手臂 | 带时间戳的观测，以及硬件允许的动作范围 |
| 感知与状态估计 | 结合图像、深度或多帧信息，估计杯子和夹爪的位置、朝向 | 物体与机器人之间的空间关系，或供策略使用的视觉特征 |
| 决策与运动规划 | 选从哪侧接近、何时闭合，给手臂找到避开桌沿的运动路径 | 抓取目标、技能指令或带时间的关节轨迹 |
| 控制与执行 | 比较目标和实际关节读数，持续修正电机输出 | 身体产生动作，新的图像和关节读数回到系统 |

难点常藏在两行之间。比如规划器说“向前两厘米”，底座的前方和手腕相机的前方可能完全不同。接口需要讲清楚相对谁、用什么单位、给的是绝对位置还是位移。时间也一样要对齐。如果杯子正在移动，把上一帧图像和这一刻的手臂位置配在一起，即使相机标定得很准，也会算错两者的距离。

下面的一维跟踪例把三个时钟单独画出来。把相机更新调慢，观察目标已经移动之后，策略要等多久才会收到新位置，以及执行器什么时候才跟上。这组教学频率与下文的 ALOHA 配置各自独立。

## 一块电池让人看懂“端到端”

在 ALOHA 双臂平台上，研究者用 ACT 学习把电池装入插槽。它把多项职责放进一个策略模型。输入是四台相机的画面和双臂当前的关节状态，输出是未来一段时间的双臂和夹爪目标位置。底层控制器再驱动电机去跟踪这些目标。这给“端到端”划出了具体的两端，一端是图像和关节读数，另一端是目标动作序列。[ACT 原论文](https://arxiv.org/html/2304.13705#S4)

作者展示的配置以 50 Hz 执行动作，每步间隔 20 毫秒，一次预测 90 步，覆盖约 1.8 秒。**预测能往前看多远，和机器人隔多久看一次现场，是两个不同的量。** ACT 的时间集成允许每步用新画面再预测，并把几次预测里对应当前时刻的动作加权。电池在接触中偏了一点，新观测就有机会改变手臂接下来的动作。[ALOHA 项目演示与参数](https://tonyzhaozh.github.io/aloha/)

## 策略是怎样做出来的

在机器人独立动手之前，还要搭起另一条流程。以模仿学习为例，操作员通过主臂遥控从臂装电池，系统同步保存图像、从臂实际位置和发给从臂的目标命令。电池抵到插槽边缘时，人还在往前送，手臂却可能停住。这两列数字一个记录想怎么动，一个记录实际动到哪，训练时各有各的用途。[ACT 的示范采集与训练](https://arxiv.org/html/2304.13705#S4)

示范可以训练观测到动作的映射。若采用强化学习，就要另外定义奖励，让策略根据行动的长期结果改进。仿真器能提供可重复的初始条件，让团队先检验碰撞、延迟和控制周期的影响。视觉—语言—动作模型（VLA）则给策略增加语言条件，使“拿蓝杯子”和“拿白杯子”可以结合画面产生不同动作。示范、奖励、仿真和语言条件分别解决不同问题，可以在一个项目里组合。[仿真专题](https://cuimingle.github.io/embodied-ai-notes/simulation/) · [策略模型地图](https://cuimingle.github.io/embodied-ai-notes/policies/)

最后要让策略独立执行，在预先约定的初始条件下记录成功次数、总次数和失败位置。假设电池总是在插槽右侧碰壁，可以按当时的画面、模型发出的目标、关节实际走过的轨迹逐项回放。画面已经显示偏差而命令仍向右，与命令已经修正而手臂没有跟上，需要改的是不同的地方。技术栈的价值，在这一次失败里就能看出来。
