# 路线与进度

作者已系统学习过一轮强化学习，并手工推导了相关公式。本工程先把这些主题整理成可检索、可讨论、可逐步验证的知识体系，再向具身智能扩展。

**进度口径**：已学过描述个人学习经历；初稿表示已有复习内容；整理完成还要求核对原稿、补齐推导并通过内容审阅。两者分别记录。

## 第一阶段：把强化学习推导串起来

| 学习单元 | 已学主题 | 工程现状 | 下一份交付物 |
| --- | --- | --- | --- |
| 问题定义 | RL definition | 初稿 | 统一状态、奖励和回报下标 |
| 递推结构 | Bellman equation、Bellman optimal equation | 初稿 | 从条件期望到固定点的逐步推导 |
| 已知模型下求解 | Value iteration、policy iteration | 初稿＋可运行实验 | 补充策略改进证明与手算例子 |
| 采样估计 | Monte Carlo learning | 初稿 | First-visit / every-visit 对照 |
| 优化基础 | Stochastic gradient algorithm | 初稿 | 从均值估计到随机逼近的推导 |
| 自举学习 | Temporal difference | 初稿＋Q-learning 实验 | MC、TD、SARSA 统一实验 |
| 从表格到参数 | Value function approximation | 初稿 | 线性价值逼近与半梯度实验 |
| 直接优化行为 | Policy function approximation | 初稿 | 对齐折扣目标与梯度估计 |
| 联合学习 | Actor-Critic | 初稿 | GAE 递推与边界单元测试 |
| 约束策略更新 | TRPO、PPO | 初稿 | KL 约束、裁剪与数值例子 |
| 组相对优化 | GRPO、GSPO | 初稿 | 对照手稿、原论文与目标函数 |

当前仅 GridWorld 的价值迭代、策略迭代与 Q-learning 有实现。深度策略训练和语言模型训练未实现。

## 第二阶段：从算法进入机器人系统

| 模块 | 需要补齐的知识 | 最小交付物 | 完成条件 |
| --- | --- | --- | --- |
| 机器人学与控制 | 坐标系、运动学、PD 控制、动作语义 | 平面二连杆与反馈控制实验 | 能说明单位、坐标与控制周期 |
| 连续控制 | DDPG、TD3、SAC，动作分布与边界 | 一个低维连续任务 | 多种子训练与独立评测 |
| 模仿学习 | BC、分布偏移、动作分块 | 一个有示范数据的小任务 | 同时记录离线误差与闭环成功率 |
| VLA | 多模态输入、动作表示、执行接口 | 公开模型输入输出检查 | 明确动作各维与执行方式 |
| 世界模型 | 动力学预测、规划、想象学习 | 一个动作条件预测实验 | 分别评估预测与决策效果 |
| Sim2Real | 噪声、延迟、接触、系统辨识 | 仿真扰动报告 | 有真实设备后再报告迁移结果 |

这些模块目前仅有路线规划，不计入已完成内容。

## 下一轮整理顺序

先核对 RL 定义与两类 Bellman 方程，再合并价值迭代和策略迭代的手算过程。随后将 MC、随机梯度、TD 的更新写成同一套记号。最后整理函数逼近到 TRPO/PPO 的推导，单列 GRPO/GSPO 的语言模型设定。

每次只推进一章：转写手稿、解释关键跳步、补最小例子、核对出处、记录仍不确定的地方。这样已有推导可以逐渐成为项目的核心内容。
